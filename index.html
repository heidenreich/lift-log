New here? The step-by-step setup guide covers everything below in plain language.

Getting your data out of Strong

  1. In the Strong app, open Settings (the Profile tab, then the gear icon).
  2. Tap Export Strong Data. Strong builds a CSV of every workout.
  3. Choose Save to Files (iPhone) or save it to your Downloads (Android).
  4. Come back here, tap Load Strong CSV and pick the file.

Getting walking data from iPhone

Web pages can't read Apple Health, so three small shortcuts save your walking data to files you load here. You build the first one, then copy it for the other two.

1. Daily steps

  1. Open Shortcuts, tap +, and name it Lift Log Steps.
  2. Add Find Health Samples. Set the type to Steps, add the filter Start Date is in the last 90 days, set Group By to Day, and sort by Start Date, Oldest First.
  3. Add Repeat with Each. It picks up the Health Samples on its own.
  4. Inside the repeat, add Format Date. Tap the date, choose Repeat Item, then Start Date. Set the format to Custom and type yyyy-MM-dd.
  5. Still inside the repeat, add Text containing Formatted Date, a comma, then Repeat Item (tap it and choose Value).
  6. After End Repeat, add Combine Text with Repeat Results, combined with New Lines.
  7. Add another Text. Type Date,Steps, start a new line, then insert Combined Text.
  8. Add Save File. Turn off Ask Where to Save, set the subpath to lift-log-steps.csv, and turn on Overwrite If File Exists.
  9. Tap ▶ to run it and allow access to Steps when asked.

2. Walking distance

  1. In your shortcuts list, press and hold Lift Log Steps, tap Duplicate, and rename the copy Lift Log Distance.
  2. In Find Health Samples, change the type to Walking + Running Distance.
  3. Change the header text from Date,Steps to Date,Distance.
  4. In Save File, change the subpath to lift-log-distance.csv.
  5. Run it and allow access to Walking + Running Distance.

3. Walks

  1. Duplicate Lift Log Steps again and rename the copy Lift Log Walks.
  2. In Find Health Samples, change the type to Workouts and set Group By to None.
  3. In Format Date, change the custom format to yyyy-MM-dd HH:mm.
  4. Change the Text inside the repeat to Formatted Date, then Repeat Item › Type, Repeat Item › Duration and Repeat Item › Distance, with a comma between each.
  5. Change the header text to Date,Type,Duration,Distance.
  6. In Save File, change the subpath to lift-log-walks.csv, then run it and allow access to Workouts.

Lift Log keeps only walking and hiking workouts from that file. Then tap Load Health files, go to iCloud Drive › Shortcuts, and select all three files at once.

Each file you load adds to what's already saved here, so running the shortcuts every week or two builds a longer history. To run them on their own, open the Automation tab in Shortcuts and create a time-of-day automation that runs each one. To run it on its own, open the Automation tab in Shortcuts and create a time-of-day automation that runs Lift Log Steps.

Add it to your iPhone home screen: open this page in Safari, tap the Share button, then Add to Home Screen. The home-screen app keeps its own copy of your data, so load your CSV again the first time you open it from there.

The export doesn't record which unit you use, so set lb or kg above to match your Strong settings. Warm-up sets are left out of records and volume. Walking data from Apple Health is kept separate from your workouts and doesn't change workout counts or the streak. Timed and distance exercises, like the elliptical or a run, appear under Cardio, and distance follows the same setting (mi with lb, km with kg). Working weight is the heaviest weight you lifted for 8 or more reps in a session. The estimated 1-rep max, in the exercise chart, uses the Epley formula (weight × (1 + reps ÷ 30)) on sets of 12 reps or fewer.
